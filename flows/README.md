# User Flows
> A user flow is a visual roadmap of your user’s journey. It lays out the steps they take to complete a specific task inside your product or service, from the first spark of “Oh, I need this” to the final “Perfect, I’m done!” (Figma)

## Rationale
User flows should be detailed to

- evaluate the user usage of the app
- provide a structured framework to follow while developing the app
- discern any missing gaps in the user experience

## Format
The user flows are present in Markdown files in the current folder consisting of

- A flowchart diagram using Mermaid
- An accompanying higher-order description of the flows
- Any limitations in the diagram or description to be explored in the future
